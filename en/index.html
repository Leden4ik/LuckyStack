LuckyStack

A web and mail server on nginx, PHP and ISPConfig. It installs with one command on a clean Debian or Ubuntu, and after that you maintain it from the panel.

Install, as root 
curl -fsSL https://raw.githubusercontent.com/Leden4ik/LuckyStack/main/get.sh | sudo bash

The command downloads the latest release, checks its signature and starts the wizard. If the signature doesn't match, nothing gets installed. You need a clean Debian 12 or 13, or Ubuntu 22.04 or newer, with at least 2 GB of RAM.

Wizard with defaults

You can just keep pressing Enter: the server name, SSH port and build profile are filled in for you.

Panel instead of SSH

Versions, checks, updates, rollback, backups, bans and notifications right in ISPConfig.

Updates without fear

A backup before the core update (nginx, ISPConfig), our changes reapplied after it, and nginx and webmail can be rolled back.

What you get on the server

Everything a hosting server needs, already set up

ISPConfig is a good panel, but after installing it the server is still far from ready. LuckyStack takes it the rest of the way to a working state and then makes sure it stays that way.

Web

nginx with HTTP/3

Built from source with Brotli, zstd and OpenSSL 3.5 LTS. Updates with one button, and the previous build is kept for rollback.

PHP

Several versions at once

From 7.4 to 8.6, with the version chosen per site. Safe session and OPcache settings, auto-tuning for the available memory.

Mail

Postfix, Dovecot, Rspamd

DKIM, SPF and DMARC, TLS for every domain, spam and virus filtering, Roundcube with ISPConfig plugins.

Security

CrowdSec and fail2ban

Bans with a shared blocklist, trusted IPs, closed ports, SSH and service hardening, malware scanning.

Data

Scheduled backups

Databases, configs, and optionally sites and mail. Restore from the panel and a copy on another server.

Maintenance

Checks and notifications

A daily monitor, email and Telegram: failed services, certificates, new security fixes, blacklists.

Updates

Why you can trust the updates

Signed releases.

Every release comes with an archive, checksums and a signature. The server installs a new version only if the signature matches.

Checks on every change.

ShellCheck, unit tests, PHP syntax checks and a scan for accidentally committed passwords on GitHub before any release.

A live test server.

End-to-end tests create a site, a database, a mailbox and a DNS zone, run a backup with a restore and the notifications, then clean up after themselves.

Rollback with one command.

The previous version of LuckyStack, nginx and Roundcube stays on the server: luckyctl rollback.
